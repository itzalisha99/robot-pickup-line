A [make.fun](https://make.fun) bounty entry. The program writes one pickup line a robot could use, in 200 characters or fewer, to `/output/entry.txt`.

## The line

> I wasn't built to feel, but my cooling fan spins every time you walk past.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

The entry is checked by a self-authored `validate()` gate that mirrors the bounty gate: UTF-8 text, 1 to 200 characters, not only whitespace, a single line.
